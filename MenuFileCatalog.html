Rename and synchronization rules

  • You may rename a menu-window HTML file in VS Code.
  • Update the matching include() line in ModuleGuideSources.html.
  • Run clasp push.
  • The HTML filename is not a Firestore identity.
  • Keep the menu-item ID and module ID stable when changing only a filename.
  • Changing a module ID requires a migration, compatibility alias, navigation rewrite and audit review.
